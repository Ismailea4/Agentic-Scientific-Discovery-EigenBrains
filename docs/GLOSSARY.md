# Glossary

| Term | Project meaning |
|---|---|
| Architecture | A bounded arrangement of solver, critic, verifier, reconciliation, and routing steps. |
| Artifact | A write-once research output with schema, stage, lineage, and content hash. |
| Availability | Probability that a provider call returns a usable response, independent of its correctness. |
| Capability | A named permission or functional requirement used as a hard feasibility constraint. |
| Common random numbers | Sharing stochastic conditions across algorithms to form a lower-variance paired comparison. |
| Conditional quality | Model quality calculated only among successful provider responses. |
| Confirmation | Evaluation of a frozen design on sealed held-out units. |
| CVaR | Conditional value at risk; the mean loss in a declared worst tail. |
| Damage | A second-stage policy changes a correct first answer into an incorrect final answer. |
| Development split | Data permitted for implementation and exploratory design. |
| EIG | Expected information gain, measured in bits in the discovery planner. |
| Evidence run | A self-describing SDK execution containing specification, provenance, artifacts, metrics, and events. |
| Held-out split | Sealed units used only after the design and policy are frozen. |
| Ledger | Append-only sequence of scientific state transitions; current state is derived by replay. |
| Operational quality | Correct outcomes divided by all attempted calls, including provider failures. |
| Pareto frontier | Candidates not dominated across all declared objectives. |
| Preregistration | Protocol frozen before confirmatory outcomes are observed. |
| Provider-backed | A step actually executed against the named external provider, not simulated by replay. |
| Replay | Counterfactual application of a policy to previously recorded paired observations. |
| Rescue | A second-stage policy changes an incorrect first answer into a correct final answer. |
| RMST | Restricted mean survival time; here, mean recovery time up to a fixed horizon with censoring retained. |
| Robust frontier | Frontier under conservative confidence bounds or stress assumptions. |
| `SAMPLE` | UI fixture; never empirical evidence. |
| Schema | Machine-checkable semantic contract for fields, arrays, metrics, units, and bounds. |
| Severe failure | Outcome meeting the protocol's preregistered high-loss definition. |
| SESOI | Smallest effect size of scientific interest. |
| Tuning split | Data used to choose thresholds, gates, hyperparameters, or roles without touching held-out data. |
| Weak prior | Prior with deliberately limited effective strength so new task data can dominate quickly. |
