## Results

**E1 — prediction (development stage, leave-one-landscape-out, 72 test runs,
prevalence 0.032, 11.7 s).** ΔAUROC vs fitness-only (AUROC 0.748 [0.701, 0.795]):

| Added features | ΔAUROC [95% CI] | Verdict |
|---|---|---|
| **population entropy (H1)** | **+0.101 [0.070, 0.134]** | supported |
| genotypic dispersion (H2) | +0.026 [0.017, 0.034] | supported (run 1: +0.031) |
| fitness spread (H3) | +0.004 [−0.010, 0.016] | inconclusive (run 1: +0.008) |

**E4 — H5, entropy beyond dispersion (16 seeds, 96 test runs, 12.5 s).**
fitness+dispersion 0.794 → fitness+dispersion+entropy 0.863:
**ΔAUROC +0.069 [0.051, 0.086]** → H5 supported. Entropy is not a proxy for
population variance.

**E7 — control (Rastrigin + Ackley, 10 seeds each, 5 shifts per run, 13.5 s).**

B3 vs the rate-matched fixed rate: ΔRMST +1.49 [−2.28, 4.76] → H6 (timing,
not rate) and H4 (vs the strongest baseline, here the rate-matched control)
inconclusive. B3's advantage over the default is explained by its lower
average mutation rate.

## Conclusions at development stage

1. Population-entropy dynamics carry substantial early-warning information
   about stagnation onset beyond the fitness history (ΔAUROC +0.10) and beyond
   genotypic dispersion (+0.07). The dispersion effect replicated across runs;
   fitness spread is null in both runs.
2. That predictive information did **not** translate into better control: a
   risk-driven mutation controller is no better than a fixed rate matched to
   its average. The default rate 1/d is itself suboptimal under shifts.
3. Nothing here is confirmed on held-out landscapes yet (that requires human
   approval by policy).

## Caveats (from the PI and critic, checked)

- H3 was labelled "refuted" (posterior 0.019) from an *inconclusive* verdict;
  the PI flagged this. Fixed in prereg v3 (composite alternative and
  status-verdict consistency); with v3 the same evidence leaves H3 open.
- The PI suggested AUROC CIs may be too narrow because test points are
  autocorrelated; the bootstrap already resamples whole runs, so that concern
  does not apply.
- Possible "detection of stagnation already under way" is mitigated by the
  at-risk definition (only generations with a fresh improvement), but a
  lead-time / false-alarm analysis has not been done.
- H4 and H6 were decided by the same contrast in E7, so they are not
  independent evidence. The 0.8/d comparator was chosen from run-1 data and
  registered before run 2.
